# ADR 0009 — Secure local deterministic pilot

Status: proposed.

Discovery: protect local API and constrain AWS collection before an approved pre-production pilot. PRE mode is deterministic only; no ACP provider, no data export to a model. All API routes require an operator-generated bearer token; missing token locks API. Host and Origin allowlists and cross-site rejection are defense in depth, not network isolation. Bind backend and UI explicitly to 127.0.0.1, never expose via tunnel or proxy. Audit metadata (method, route template, status) uses process logs; no prompt, header, raw URL, identity or response contents. Disable Uvicorn access logs. UI token held in memory only, never in VITE variables or browser storage.

AWS tool requires explicit approved profile, region and expected 12-digit account; validates STS caller identity before each collection using the same native AWS CLI/profile/region. Account check is a guardrail, not an IAM boundary; trusted operator configuration and least-privilege IAM still required. Use a dedicated database in an OS-private directory; do not mix environments. No automatic login. In PRE set AGENTJAM_POC_MODE=pre and AGENTJAM_PROVIDER=mock in API and all workers; do not run ACP or attach corporate skills to a model. PRE mode cannot constrain another process with different environment or access to local files. Only a separate OS identity/sandbox can constrain harness access; use separate disposable environment for real ACP validation. No OIDC, RBAC, encrypted SQLite, tamper-proof audit, OS isolation, process-tree containment or production approval; issue #5 remains open. Real AWS/SSO and browser E2E require approved validation.
